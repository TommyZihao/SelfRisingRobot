# RoBoBo 4.1.2-PCB

作者：同济子豪兄 2026-10-26。打包日期：2026-11-13。
原始机器人项目：HomeMadeGarbage / SelfRisingRobot；保留原作者贡献。

本版重新训练右侧翻，并扩大前进、后退的往复动作。保留雄起机、不倒翁、动作模式、GPIO镜像输出、PWM标定、屏幕操作及200Hz姿态回传。已编译、打包并于2026-11-13烧录到ATOM S3R，写入校验通过、串口姿态查询正常；本版真机运动效果尚待评估。此目录为GitHub发布副本。

## 本次选择和独立测试

全部从实际落稳的`pitch_neg`起步，随机舵机初态和物理参数。舵机按5V近似，末端为橡胶圆帽，地面为地毯近似；这些物理参数未实测标定。

| 动作 | 选定算法 | 独立100次通过率（旧→新） | 平均沿指令方向净进度（旧→新） |
|---|---|---|---|
| 右侧翻 | `right_mirror_2101`，镜像初始化后PPO补训 | 0% → 69% | 24秒32.6° → 86.2° |
| 前进 | `forward_heading_2502`，CEM周期动作+方向反馈 | 25% → 53% | 32秒3.2cm → 27.4cm |
| 后退 | `backward_heading_2701`，CEM周期动作+方向反馈 | 0% → 80% | 32秒3.7cm → 22.2cm |

前进与后退最终选中的不是PPO神经网络，而是经过搜索的周期关节目标和IMU方向修正。对比了14组PPO（共11,210,752环境步），以及10组周期动作/反馈参数搜索，按单独验证集选定，再用新随机种子复核。没有只挑好看的单次轨迹。

右翻通过定义：净翻转达到86.4°并保持0.2秒，结束仍净翻转至少72°且没有站起；**不是连续翻多圈成功率**，新策略100次中没有完成净180°的持续翻转。前后移动通过定义：32秒沿指令净移动至少4cm，后16秒的8个窗口中至少6个推进2mm以上，末端朝下占比>60%、接触占比>40%、航向偏差<45°、横向偏移受限且未站起。不同动作成功率不能横向比较；与之前旧报告的不同判据也不能直接比较。

前进下/上舵机目标的峰峰摆幅平均约100.6°/81.9°，后退约119.7°/124.5°。摆幅不是正负角度：119.7°约相当于总往复范围120°。前后移动下关节目标约束为±60°，上关节物理范围仍±120°；每20ms目标增量限制为0.06/0.08rad。末端始终接地不作保证，周期中允许抬起再落下。仿真接触最大穿透约3.5–4.5mm，软接触/摩擦尚未标定，真实效果需另测。

## 操作与保留功能

- 上电默认雄起机；43°触发、等待和最后归零动作保留。不倒翁继续用已验证V3.1起身核心。
- 左翻和左右偏航沿用4.1，不宣称本次改善了这些动作。
- 蛄蛹者按住持续执行；心跳不重启周期；松开保持当前目标；换向保留当前实际姿态。其它初始倒地方向尚未验证可靠性。
- 回零位停止缓慢回零后自动进入蛄蛹者空闲待命，无需再点击恢复，不自动重复旧命令。暂停、切换模式或离开网页会取消自动恢复。
- 运动时400ms失去控制消息停止；空闲不报运动超时。短暂HTTP错误可重试，已失效会话不会自动重启运动。按住期间命令回复携带姿态，避免独立轮询争抢网络；真机网络延迟仍待复测。
- GPIO1/39同步控制下舵机，GPIO2/38同步控制上舵机；每组只接一路信号。PWM标定仍读取原Preferences。
- Wi-Fi `RoBoBo`，地址`192.168.42.1`。姿态回传200Hz，默认关闭。网页正常状态100ms请求周期，图表约25Hz采样并插值；按住时约75ms发起命令并随回复更新状态，实际取决于网络。舵机显示为目标值，不是实际关节角反馈。

## 文件和验证

- `firmware/robo03_atom_s3r_4_1_2_PCB/`：工程、网络头文件、前后步态配置、控制器、导出和测试。
- `build/RoBoBo_4.1.2-PCB.merged.bin`：完整镜像；其它bin为同次编译分区。
- `models/`：原始策略权重、前后周期参数和来源说明。`forward_gait_search32.json`仅为旧版基线，不在本版运行。
- `simulation/`：橡胶圆帽XML及网格；蓝色网格地面。
- `docs/report.html`：各组训练曲线、评估指标、首个固定测试视频及明确标记的挑选案例。`docs/PROTOCOL.txt`为方案；JSON保留每次评估记录。
- `pc_viewer/`：200Hz实时姿态查看器；沿用本体可视化，不模拟真实世界位移或实测关节角。
- `validation.json`：编译、回归和仿真结果；`SHA256SUMS.json`：文件校验。

编译：m5stack ESP32 core 3.3.8、M5Unified、ESP32Servo、Kalman。

```sh
arduino-cli compile --fqbn m5stack:esp32:m5stack_atoms3 firmware/robo03_atom_s3r_4_1_2_PCB
python3 verify_package.py
python3 firmware/robo03_atom_s3r_4_1_2_PCB/tests/test_parity.py --models models
python3 firmware/robo03_atom_s3r_4_1_2_PCB/tests/test_web_hold.py
python3 firmware/robo03_atom_s3r_4_1_2_PCB/tests/test_link_recovery.py
python3 firmware/robo03_atom_s3r_4_1_2_PCB/tests/test_home_resume.py
```

网络验证需NumPy、PyTorch、Stable-Baselines3及C++编译器。完整逐步仿真一致性测试额外传`--rl /path/to/SelfRisingRobot-main/RL`，需要原研究目录。四个网络导出与六动作逐步控制已验证，最大逐步目标误差小于0.000003rad。固件占用1,431,231字节Flash、51,924字节静态RAM。前后算法不是网络，头文件配置已按同一数学实现验证。

Mac端先运行`pc_viewer/setup_viewer.sh`。连接热点、网页开启姿态回传，再运行`pc_viewer/pc_mujoco_viewer.command`。查看器自检已通过。
